AKUMA STORE - catálogo de juegos
1) Creá una cuenta en RAWG y obtené una API key: https://rawg.io/apidocs
2) Abrí config.js y reemplazá PEGAR_AQUI_TU_CLAVE_API por tu clave.
3) Subí index.html, config.js y logo.png a GitHub Pages.
El catálogo consulta juegos en tiempo real y permite filtrar PS3/PS4/PS5, buscar, ver portada, género, fecha, plataformas y descripción, y consultar por WhatsApp.
RAWG exige atribución/enlace cuando se usa su API y sus imágenes/datos están sujetos a sus términos.
